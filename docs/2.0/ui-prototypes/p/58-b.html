Map at peak

58-b · the holdings map, designed for twenty workstreams first
Scenario
What the map gives up at Peak
  • Only the picked island and the ones that fit are full size. The rest are rings with a count of what they hold.
  • A ring shows ripples and subagent dots, not ports, tabs or sizes. Hover it to see them.
  • A full island draws three agents and four nodes in a row. More fold into a +n node. Each server gets one browser node with an icon per browser.
  • Names cut short with an ellipsis rather than overlap. The hover card has the full name.
  • Past six, leftovers merge into one bubble. Its card lists them by kind.
  • Lists in the Advanced tabs scroll instead of fitting on one screen.
Facts drawn. Lines follow an agent's cwd, a server's worktree field, a cache's ownerPath and a tab's localhost port. Agent state is working, waiting or idle with its why. A question shows only when the hook reports it. Subagent dots count reported starts and clear when the turn ends. A ripple is new connections in a sample. Wrap Up lists the plan parts in run order with each whyNot, and keeps disk and memory apart. Undo restarts stopped servers. A helper whose parent exited stays stopped. New. Closing a workstream's localhost tabs is drawn as a part of Wrap Up. The code can close tabs by id and reopen them, but no Wrap Up part does it yet.
